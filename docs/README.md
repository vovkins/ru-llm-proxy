# Документация ru-llm-proxy

Выберите документ по задаче. Подробности не дублируются: поведение описано в
архитектуре, настройки — в справочнике конфигурации, API-запросы — в примерах,
а эксплуатационные процедуры — в профильных руководствах и мониторинге.

## Начало работы

| Задача | Документ |
| --- | --- |
| Запустить проект и выполнить первый запрос | [Главный README](../README.md) |
| Понять компоненты, порядок проверок и границы данных | [Архитектура](architecture.md) |
| Настроить `.env` и Docker Compose | [Конфигурация](configuration.md) |
| Выполнить запросы и проверить режимы | [Примеры API](examples.md) |

## Технические материалы

Материалы в [`research/`](research/) фиксируют происхождение модели, результаты
сравнений и доказательства проверок. Они не являются инструкциями по эксплуатации.
Для активной NER-модели начните с
[происхождения и обновления модели](research/ner-model-provenance.md); подробная
матрица проверок находится в
[ner-migration-test-coverage.md](research/ner-migration-test-coverage.md).

## Правила поддержки

- Основной язык — русский; английские названия остаются у продуктов, API,
  параметров, полей и команд.
- Новую настройку описывайте в [configuration.md](configuration.md), а проверочный
  запрос — в [examples.md](examples.md).
- Метрики, события журналов и действия при сбоях описывайте в
  [monitoring.md](monitoring.md).
- Исторические отчёты храните в `research/` и не представляйте как актуальное
  руководство.
