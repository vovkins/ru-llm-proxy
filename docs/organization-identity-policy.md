# Критерий защиты названия организации

По указанию пользователя оценивается само название. Открытая юрформа
ООО/АО/ПАО/ОАО/ЗАО в начале размеченного значения и пробелы учитываются отдельно;
они не объявляются утечкой названия. Юрформа внутри названия и все остальные
символы не исключаются автоматически. Для других типов критерий не меняется.

Старый span-based отчёт сохраняется рядом с новым identity-отчётом. При JSON
Unicode escapes исключения применяются после точного проецирования реального
строкового скаляра в исходные координаты.

Достроенный NER-диапазон теперь начинается не раньше первого принятого
фрагмента. Если само название уже найдено, правило может уточнить тип до
ORGANIZATION, сохранив открытую юрформу. Ранее принятые фрагменты не теряются.

Изолированный исходный вариант сохранён. Новые показатели не доказывают
полноту защиты: полностью пропущенные названия оцениваются отдельно,
прежние цифры не перезаписываются.
