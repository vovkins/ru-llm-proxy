## Интерпретация

Точное совпадение требует одинакового типа и одинаковых границ. Покрытие правильным типом допускает более широкий интервал. Покрытие для маскирования учитывает любой результат Analyzer, полностью закрывающий ожидаемое чувствительное значение.

Эта исходная точка не является критерием приёмки сама по себе. Новая модель сравнивается с ней на том же корпусе и должна выполнить пороги качества из задачи #67.

Операционные свойства холодной сборки и запуска зафиксированы в [отдельном отчёте](ner-migration-baseline-observations.md).
