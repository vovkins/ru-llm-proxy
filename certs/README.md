# Корпоративный корневой сертификат

Для работы через корпоративный прокси, который переподписывает TLS-соединения,
поместите согласованную цепочку корневых и промежуточных сертификатов в файл:

```text
certs/proxy-ca.crt
```

Файл должен быть в формате PEM и может содержать несколько блоков
`BEGIN CERTIFICATE`. Получите цепочку у команды сетевой безопасности, не
выгружайте ее с непроверенного узла.

Во время сборки сертификат добавляется:

- в системное хранилище доверия образа Analyzer;
- в `certifi` внутри среды LiteLLM;
- в хранилище тестового образа защитного слоя.

Проверка TLS остается включенной. Использовать `SSL_VERIFY=False` или похожие
обходы не требуется.

Файлы `certs/*.crt`, `certs/*.pem` и `certs/*.key` исключены из Git. В
репозитории хранится только эта инструкция.
